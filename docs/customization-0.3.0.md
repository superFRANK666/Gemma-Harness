# 0.3.0 外观与项目管理

## 外观

在「设置与连接 → 外观」选择浅色、深色或跟随系统主题，并选择鼠尾草绿、海蓝、紫罗兰、琥珀强调色。界面字体和代码字体分别配置，代码字体也应用于文件编辑器与终端。界面字号范围为 11–18 px，代码字号为 10–18 px；字体使用设备本地字体栈，不下载远程字体。

更改立即预览。取消、关闭设置或点击遮罩会恢复已保存的外观；「恢复默认外观」同样先预览，需要保存后才持久生效。跟随系统会实时响应系统主题变化。

只改外观时使用独立保存接口，不清除当前消息、不停止终端或模型请求，也不重置 MCP。若同时修改连接、设备等设置，则遵循原有的任务停止要求。后台会话刷新不会覆盖仍在预览的外观。

## 项目

项目栏的「+」打开并记住本地文件夹。通过执行设备设置选取的本地／远端工作目录也会登记到项目列表。原版已有工作目录和会话目录在第一次启动时迁入；相同目录名、不同路径或不同执行设备不会混为一个项目。

项目旁的「…」菜单提供：

- **重命名**：修改列表、标题中的显示名称；保持真实文件夹路径及历史会话执行绑定不变。
- **移除项目**：从列表移除，保留本地／远端文件、Git 仓库及历史会话。移除当前项目后回到未选择项目状态，可再次添加文件夹。

移除的项目不会因应用重启或读取旧会话而自动回到列表。任务或手动终端运行时禁止切换／移除项目；重命名显示名称仍可用。项目注册／移除与配置持久化共用 SQLite 事务，写入失败会整体回滚。

## 验证

本轮自动检查覆盖外观预览、取消回退、保存重启、系统主题监听、混合保存、运行中改外观、最大字号布局、保存失败，以及项目改名／移除、历史保留、运行中导航保护和失败重试。Rust 回归使用真实 SQLite／临时文件，包含迁移、跨设备绑定、取消准入和模拟配置写失败的事务回滚。

工程测试结果、当前安装包校验值及原生交互记录见 [验收记录](acceptance.md) 与 [结构化验证结果](verification.json)。本轮未改变模型、推理引擎或远端协议，原有真实模型及跨平台桌面验收边界保持。
